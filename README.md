# Bilawal Faiz — GitHub Pages Portfolio

## Publish using GitHub Pages

1. Sign in to GitHub as `BilawalFaiz5`.
2. Create a **public** repository named exactly `BilawalFaiz5.github.io`.
3. Upload `index.html`, `robots.txt`, and `sitemap.xml` from this folder to the repository root (not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The expected URL is:
   https://bilawalfaiz5.github.io/

If you use a repository with a different name, the site URL and the canonical, sitemap, and structured-data URLs in `index.html` and `sitemap.xml` must be changed to match.

## Google indexing steps

1. Open Google Search Console: https://search.google.com/search-console/
2. Add the website as a URL-prefix property: `https://bilawalfaiz5.github.io/`.
3. Verify ownership using one of the methods Google offers. Follow the exact method displayed in Search Console.
4. After the site is live, submit `https://bilawalfaiz5.github.io/sitemap.xml` in the Sitemaps section.
5. Use URL Inspection for the homepage and choose **Request indexing**.
6. Link to this website from your public LinkedIn, Facebook, TikTok, and GitHub profiles where each platform allows it. Keep your public name consistent as “Bilawal Faiz”.

## Notes

- Search engines may take days or weeks (sometimes longer) to crawl and index a new site. Indexing and rankings are not guaranteed.
- Keep the profile information accurate. Replace any description or project links that are not accurate for you.
- No paid hosting is needed for a static portfolio on GitHub Pages.
